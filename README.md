# SOLEAD Finance

Локальное приложение для учёта обязательств и фактических выплат в RUB и USDT.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей не требуется. Шрифт DM Sans загружается из Google Fonts; без сети используется системный шрифт.

## Возможности

- Реестр обязательств, группы, фильтры, сортировка и избранное.
- Карточки лиц с раскрывающимися контактами.
- Сроки, графики и запись фактических выплат.
- История операций, отмена последнего изменения, график выплат.
- Экспорт и импорт JSON, скрытие сумм.
- Адаптивное тёмное оформление SOLEAD Dark.

## Данные

Репозиторий содержит пустой реестр. Данные сохраняются в localStorage конкретного браузера. Между устройствами и адресами сайта они автоматически не синхронизируются. Для переноса используйте «Экспорт данных» на исходном устройстве и «Импорт копии» на новом. Импорт заменяет реестр: сначала сохраните текущую копию.

Не добавляйте финансовые записи, контакты или экспорты в Git. Функция записи выплаты ведёт учёт и не выполняет денежный перевод. RUB и USDT учитываются отдельно; курс валют не выводится.

## Проверка

Требуется Node.js:

```sh
node --test model.test.cjs storage.test.cjs
```

## Оформление

Собственный интерфейс по визуальному референсу Sologenic: тёмные панели, красный акцент, тонкие контуры и компактные элементы управления. Логотипы и исходный код Sologenic не используются.
