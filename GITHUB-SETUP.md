# SOLEAD: размещение на GitHub

## 1. Распакуйте архив

Распакуйте SOLEAD-GitHub.zip через «Извлечь всё». Загружать нужно содержимое распакованной папки, а не ZIP-файл. В корне репозитория должны оказаться index.html, app.js, model.js, style.css и seed.js.

## 2. Создайте репозиторий

1. Войдите в свой аккаунт на https://github.com.
2. Откройте https://github.com/new.
3. В поле Repository name укажите solead-finance.
4. По желанию добавьте описание: Personal finance tracker — SOLEAD.
5. Выберите Private для закрытого репозитория или Public, если хотите открыть исходный код всем. Для хранения проекта достаточно Private.
6. Включите создание README, чтобы сразу появилась страница с файлами.
7. Нажмите Create repository.

## 3. Загрузите файлы

1. На странице репозитория выберите Add file → Upload files.
2. Перетащите все файлы из распакованного архива в область загрузки. Загружайте файлы непосредственно в корень, без дополнительной папки SOLEAD.
3. Убедитесь, что index.html находится на верхнем уровне. Если .gitignore скрыт в Проводнике, его можно отдельно создать через Add file → Create new file; он содержит правила исключения приватных файлов.
4. В сообщении сохранения укажите Initial SOLEAD version.
5. Сохраните загрузку кнопкой Commit changes. Если предложено Propose changes, завершите создание и слияние запроса изменений.

README из архива заменит автоматически созданный README.

## 4. Проверка

В списке файлов должны быть index.html, style.css, app.js, model.js и seed.js. Чтобы запустить приложение локально, откройте распакованный index.html в браузере.

Сам репозиторий хранит код. Ссылка вида github.com/логин/solead-finance открывает страницу проекта, а не работающее приложение. Для запуска приложения по интернет-ссылке отдельно настраивается хостинг, например GitHub Pages. Публикацию сайта в этой инструкции не выполняем.

## Данные

В архиве пустой начальный реестр. Личные финансовые записи, контакты, экспорты и резервные копии не включены. Рабочее приложение на исходном компьютере не меняется.

Текущие записи хранятся в браузере конкретного устройства и адреса. Для переноса используйте «Экспорт данных», затем «Импорт копии» в приложении на новом устройстве. Импорт заменяет существующий реестр, поэтому перед ним сохраните копию. Не загружайте экспорт с личными данными в репозиторий.
